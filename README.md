# Money Moves

**Money Moves** is a skills-first personal finance workflow for ChatGPT.

It turns financial context already available in ChatGPT, plus the user's own limits and rules, into practical daily money guidance.

## What it does

- Morning Money Moves briefs
- Evening changes-only briefs
- Monthly spend-down trackers
- Cash-protection and safe-to-spend reasoning
- Recurring-charge change detection
- Stale-data and user-correction handling
- Practical next-step guidance

## Privacy-first design

Money Moves v0.2 does **not** require:

- a separate Money Moves account;
- a separate bank connection;
- a Money Moves financial dashboard;
- sending bank data to a Money Moves server.

The skills-only plugin uses financial context available to the user inside ChatGPT. Retro Services does not receive or store bank credentials, balances, transaction histories, card numbers, or financial account identifiers through this release.

## Safety

Money Moves is informational and advisory. It does not move money, pay bills, trade assets, open or close accounts, apply for credit, or change payment settings.
